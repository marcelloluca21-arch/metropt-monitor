# MetroPT Monitor

## Obiettivo

MetroPT Monitor è un progetto end-to-end basato sul dataset MetroPT-3. L'obiettivo è analizzare la telemetria di un compressore ferroviario, rilevare anomalie e confrontarle con i guasti documentati.

Il progetto comprenderà una pipeline per i dati, modelli di machine learning, un'API, un'applicazione web dimostrativa e report in Power BI.

## Stato attuale

Il repository contiene la configurazione Git e un notebook con la prima lettura esplorativa del CSV. La pipeline, i modelli e le applicazioni devono ancora essere sviluppati.

## Dati

Il progetto utilizza il file `MetroPT3(AirCompressor).csv`. Il CSV originale rimane locale ed è escluso da Git per le sue dimensioni.
